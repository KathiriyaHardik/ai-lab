# Evaluating LLM answers

Write the test questions and the expected answers before the first run, so you don't adjust the test to the results.

Run the whole test several times. Language models are a little random, and one good run can hide a problem.

Check facts with code where possible, for example whether a quote really appears in the source. Letting another model judge the answer is cheaper to set up but can share the same mistakes. See [[RAG basics]].
