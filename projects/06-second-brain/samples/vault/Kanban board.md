# Kanban board

A Kanban board has columns like To do, Doing and Done. Every task is a card that moves from left to right.

The key rule is a work-in-progress limit: at most 3 cards in Doing at the same time. Finishing beats starting.

It also works outside software projects, for example to track job applications from "found" to "applied" to "interview".
