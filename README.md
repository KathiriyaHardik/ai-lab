# practice-lab

A sandbox for small practice projects.

## Layout

```
projects/
  01-<name>/   # each practice project gets its own numbered folder
  02-<name>/
```

## Workflow

1. Create a folder under `projects/` (e.g. `projects/01-todo-cli`).
2. Add a short `README.md` in it: goal, what you learned, how to run it.
3. Commit as you go.
